## Operational Notes
* **Alarm Thresholds:** Set automated data-logger alarms to trigger if spawn run block temperatures approach $26.5^\circ\text{C}$, allowing immediate cooling intervention before reaching the $27^\circ\text{C}$ lethal limit.
* **Calibration Schedule:** Verify and recalibrate $\text{CO}_2$ and temperature sensors weekly.
