## 3. Corrective Action Codes

| Code | Action | Use when |
| :--- | :--- | :--- |
| **C1** | Increase recirculation | Compost ≥ 26.5 °C |
| **C2** | Introduce cooler outside air (night/early morning) | Compost ≥ 26.5 °C and outside air < room air |
| **C3** | Open bag tops / lift covers | Compost ≥ 26.5 °C |
| **C4** | Re-space bags (≥ 5 cm gaps) | Persistent > 26 °C |
| **C5** | Lower air setpoint 2 °C (K2) | Compost ≥ 26.5 °C |
| **H1** | Close vents and doors fully | Compost < 22 °C |
| **H2** | Thermostatic heater on | Room air < 19 °C at night |
| **R1** | Mist walls/floor | RH < 88% |
| **X1** | Contamination removed (record type and location below) | Any contamination |
| **X2** | Fly activity: screens/doors checked, traps added | Flies seen or trap count > threshold |
| **E1** | Escalated to manager | Any critical threshold (Deliverable-101 §2) |
